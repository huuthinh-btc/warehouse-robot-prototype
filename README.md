\# Warehouse Robot Prototype



\## Project Description



This project is a prototype of a warehouse management system that simulates the operation of robots in a warehouse environment.



The system is built to demonstrate how robots and warehouse management functions can be integrated into a monitoring system.



The prototype includes basic interfaces and backend APIs to simulate warehouse operations.



\---



\## Demo Functions



The prototype demonstrates three main functions of the warehouse system:



\### 1. Product Management



Allows warehouse staff to monitor and manage products stored in the warehouse.



Main capabilities:



\* View the list of products in the warehouse

\* Check product stock levels

\* View product expiration dates

\* Identify the shelf location of each product



\---



\### 2. Robot Task Management



Allows the system to create and manage tasks assigned to warehouse robots.



Examples of tasks:



\* Refill shelves

\* Handle misplaced products

\* Check expired products



The system tracks the task status such as processing, completed, or error.



\---



\### 3. System Monitoring Dashboard



Provides an overview of warehouse system operations.



Displayed information includes:



\* Distribution of warehouse tasks

\* Robot working status

\* Products that generate the most operational issues



The dashboard helps supervisors monitor warehouse activities in real time.
